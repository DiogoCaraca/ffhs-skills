# Über Spickzettel-Print

Alles hier ist für den **Ausdruck oder das Offline-PDF** gedacht. Am Prüfungstag gibt es kein Obsidian: keine Wikilinks, keine Suche, kein Dataview.

- [[<Modulcode> - Spickzettel]]

## Aufbau pro LE

1. `> [!tip]` **Übersicht** - welches Werkzeug / Verfahren für welche Frage
2. Pro Thema:
   - **Kurzeinstieg** - 1-2 Sätze, was es ist und wozu
   - `> [!important]` **Definition / Formeln**
   - **Tabellen** - Fälle, Varianten, Beispiele mit ✓ / ✗
   - **Rezept** als nummerierte Schritte, wo es ein Verfahren gibt
   - `> [!example]` **Anwendungsbeispiel** - kursive Aufgabe, kurze Rechnung, Probe
3. **Code-Cheatsheet** (falls das Modul Code verwendet) - ein Block, nummerierte Abschnitte `# (1)`, Ausgabe als Kommentar `# -> ...`, vorher ausgeführt und geprüft
4. `> [!warning]` **Häufige Fehler** - nummeriert, Fehler fett
5. Quellenzeile mit Seitenzahlen

## Regeln

- **Anwenden, nicht erklären.** Wer den Spickzettel braucht, kennt das Thema schon halbwegs. Theorie nur als Kurzeinstieg (1-2 Sätze), keine Herleitungen. Erklärt wird in den Konzeptnotizen.
- **Verdichten, nicht sammeln.** Tabellen statt Fliesstext. Richtwert: rund 1200 Wörter pro Lerneinheit ohne Code.
- **Voraussetzungen mitschreiben** - *gilt nur, wenn …*
- **Fallen markieren**: Vorzeichen, Reihenfolge, Konventionen, Druckfehler im Lehrmittel.
- **Echte Seitenzahlen** aus den Kapitellandkarten in `07_Quellen`.
- **In Tabellen kein nacktes `|`** - Betrag und Norm als `\lvert…\rvert` bzw. `\lVert…\rVert`.
- **Nach jeder Lerneinheit nachfüllen**, damit der Zettel vor jedem Kurztest bereitliegt.
